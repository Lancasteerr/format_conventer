## 项目简介

图片格式转换器用于在本地批量处理常见图片格式。你可以通过按钮选择图片，也可以将图片直接拖拽到应用中，再选择输出目录、目标格式和质量参数，最后一键完成转换。

当前项目主打简单、直接、离线可用：图片读取、格式转换和文件输出都在本机完成，转换过程会显示进度、每个文件的状态、输出路径或错误信息，并在支持质量调节的格式中提前预估输出大小。

## 功能特性

- 支持导入 JPG / JPEG / PNG / GIF / WEBP 图片。
- 支持转换为 JPG / PNG / GIF / WEBP。
- JPG / WEBP 支持质量调节，默认质量为 `85`。
- 支持批量选择文件和拖拽导入文件。
- 转换时显示整体进度、单文件状态、输出路径或错误信息。
- 支持输出大小预估，方便在转换前判断压缩效果。
- 输出文件会自动避让同名文件，避免覆盖已有图片。
- GIF / WEBP 互转时会尽量保留动画信息；转为 JPG / PNG 时使用首帧输出。

## 开发教程

### 1. 安装依赖

```bash
npm install
```

### 2. 开发运行

```bash
npm run dev
```

### 3. 使用应用

1. 点击“选择图片”批量导入图片，或直接将图片拖拽到应用区域。
2. 点击“输出目录”选择转换后的文件保存位置。
3. 选择目标格式：JPG、PNG、GIF 或 WEBP。
4. 如目标格式为 JPG 或 WEBP，可拖动质量滑块调整输出质量。
5. 点击“开始转换”，等待列表中的状态变为“完成”。

### 4. 打包 Windows 便携版

```bash
npm run dist:win
```

打包产物会输出到 `release` 目录，文件名格式为：

```text
Format_conventer-版本号-portable.exe
```

## 项目结构

```text
src
├─ main       Electron 主进程，负责窗口、IPC、文件选择和图片转换
├─ preload    预加载脚本，向渲染进程暴露安全的图片转换 API
├─ renderer   React 渲染进程，负责界面交互、文件列表和进度展示
├─ shared     主进程和渲染进程共享的类型、格式和 IPC 定义
└─ tests      Vitest 单元测试
```

## 设计说明与后续优化

当前项目将桌面能力和界面能力分开处理：主进程负责文件系统访问、图片元数据读取和 sharp 转换；渲染进程负责用户交互、导入列表、进度展示和输出大小预估；共享层统一维护类型、格式和 IPC 通道。
